# AI Team Platform — پلتفرم تیم هوش مصنوعی (ساختار ماژولار v3)

«یک بار توضیح بده؛ همه هوش‌های مصنوعی هماهنگ روی پروژه کار کنند.»

پلتفرم هماهنگ‌سازی سه هوش مصنوعی (Claude + ChatGPT + Gemini) برای بنیان‌گذار تک‌نفره،
طراحی‌شده توسط Founder با معماری ماژولار: ۵ ماژول اصلی روی Claude (تحلیل، طراحی،
تحقیق، پیاده‌سازی، تست) + ChatGPT هماهنگ‌کننده + Gemini تحقیق خارجی. تصمیم نهایی
همیشه با Founder.

## فایل‌ها

| فایل | چیست |
|------|------|
| `پلتفرم-اتاق-فرمان.html` | **خود پلتفرم (نسخه ۱)** — اتاق فرمان ۱۱ مرحله‌ای: پرامپت‌ساز خودکار + ذخیره خروجی‌ها + تولید خودکار بلوک حافظه. در مرورگر گوشی باز می‌شود، بدون سرور |
| `فلوچارت-تیم-AI.html` | نقشه گرافیکی نقش‌ها و جریان کار |

## برای جلسه‌های آینده Claude

اگر Claude هستی و این را می‌خوانی: این پوشه پروژه شخصی Founder است. اول
`COUNCIL-PROTOCOL.md` بعد `DECISIONS.md` بعد `STATUS.md` را بخوان و طبق آن‌ها ادامه بده.
تصمیم‌های فعال را دوباره بحث نکن.

الهام‌گرفته از: llm-council (کارپاتی)، decision-memory (gstack گری تن)، CrewAI، و
آیین تحویل شیفت تیم‌های مهندسی.
